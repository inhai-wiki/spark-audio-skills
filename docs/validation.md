Agent 依据转写选择三个高光并编写摘要。摘要由 Agent 写入清单，ASR 提供识别文字和时间信息。各片段均导出 MP3 与 MP4，同时生成可读的 `highlights-audio.md` 和 `highlights-video.md`。

## 早期文件转写与切片小样

将下述 TTS 样例重新整理为 16 kHz 单声道 MP3，通过录音文件转写大模型提交 1 次上传，查询 2 次后取得完整结果。使用默认 `autodialect`，角色分离关闭，文本顺滑及口语规整均关闭。

- 源音频长度为 12.58 秒；返回 1 个句子及 36 个词／标点时间项。
- 去除标点后，识别文本的 51 个汉字与合成脚本一致；标点与原脚本有差异。该检查仅适用于这一段清晰合成语音，不作为准确率基准。
- 按实际返回的词时间和已知轮次边界，选择讲解部分 `5.33–12.29` 秒，输出 6.96 秒 MP3 切片。原始音频哈希未改变。
- 再次运行相同任务时返回 `cached: true`，没有重新上传。
- 该后端通过真实小样联调；可选的短音频听写 V2.0 后端仅完成模拟协议测试。

## 验证边界

- 本轮 B 站视频完成了真实录制素材的转写与切片，但没有人工逐字稿及错误率统计。早期合成语音小样只用于接口衔接检查。两者都不能替代系统性的噪声、方言、专业术语评测或竞品对比。
- 音频／视频解码检查确认文件完整可读，未将其记作主观音色盲听或逐个切口的听感验收。
- 文件转写返回的句／词时间由服务提供，切片仍需要回听；可选 V2.0 后端只提供分段级粗时间轴。
- 双人播客采用角色轮流发言，字幕按生成段长排布，尚无段内逐字对齐。
- 未做满 5 小时文件、企业高并发、长期故障恢复和成本压力测试。批量任务采用顺序执行。
- 视频音轨起点偏移超过 50 毫秒时会拒绝预处理，需先校准源素材。
- 开源项目采用 MIT 许可，仓库与使用入口见 README。
