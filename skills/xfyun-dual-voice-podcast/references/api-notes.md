# 讯飞超拟人语音合成接口

核对日期 2026-11-25。

官方依据为 [超拟人语音合成 WebAPI 文档](https://www.xfyun.cn/doc/spark/super%20smart-tts.html) 与 [产品页](https://www.xfyun.cn/services/smart-tts)。已完成两轮、56 字符的真实接口联调，使用聆飞逸与聆玉言生成 12.58 秒样例；这一结果验证调用和拼接，不代表综合音质或并发评测。

- 端点为 `wss://cbm01.cn-huabei-1.xf-yun.com/v1/private/mcd9m97e6`。
- 本实现采用请求头 `x-api-key` 传入控制台 APIPassword。请求体 `header.app_id` 使用该服务的 AppID。
- 每段完整文本以 UTF-8 编码后做 Base64，置于 `payload.text.text`。`header.status` 与 `payload.text.status` 均为 2，`seq` 为 0。服务端继续分帧返回音频。
- 要求 raw PCM、24 kHz、16 bit、单声道。根据响应 `audio.seq` 整理音频，收到终态才保存完整 WAV。未收到终态的部分音频不能作为成功缓存。
- `parameter.oral` 结构表标为必传，本实现传空对象。口语化参数仅 x4 系列支持，x6 不附加 `oral_level` 等控制。
- 每次会话文本不得超过 64K 字节。本实现主动以 12,000 字节预算拆分，逐段建立会话，避免跨声线混用。
- 原始 PCM 没有 MP3 元数据。最终 MP3 的 AI 声音标识由发布流程处理，交付同时提供 `provenance.json` 与脚本内提示。

## 输出与恢复

逐段 `state.json` 只记录状态、字符数、请求次数和服务 sid，不保存密钥。`uncertain` 表示请求已发出但结果无法确认，费用也无法由本地状态确定。显式重试可能再次产生费用。

`requests.json` 包含文本与音色设置，适合做复现记录。将整个输出目录用于公开发布前，先检查文稿内容和来源文件路径是否适合公开。只分享节目成品时无需上传内部状态与缓存。
